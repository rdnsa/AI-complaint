Hasil di atas berasal dari basis commit fccd959, 4 November 2026. Suite dijalankan penuh empat kali berturut-turut tanpa satu pun kegagalan tak terduga. Suite terdiri dari 279 test ditambah 1 langkah login: 167 test API, 91 test UI desktop, dan 21 test UI HP.

Kepekaan suite juga sudah diuji dengan sengaja merusak empat aturan di kode aplikasi, lalu memulihkannya: laporan selesai bisa dibuka kembali, API akun tanpa pemeriksaan hak akses, klaim tanpa nama, dan kirim laporan tanpa foto. Keempatnya ditangkap suite.

Hijau bukan berarti bebas bug. Ada 13 bug nyata yang masih terbuka, tiga di antaranya berat: lihat bagian 7. Suite tetap hijau karena bug itu ditandai sebagai known issue.

2. Cara menjalankan

Hanya perlu dipasang sekali:

npm install
npx playwright install chromium

Tidak perlu npm run dev, tidak perlu .dev.vars, tidak perlu API key, dan tidak perlu login Cloudflare. Test menyalakan semuanya sendiri.

PerintahKegunaan
npm run test:e2eSemua test. Jalankan ini sebelum merge atau deploy.
npm run test:e2e:apiTest API saja, tanpa browser. Sekitar 20 detik, cocok saat mengubah src/.
npm run test:e2e:smokeSatu perjalanan penuh: pelapor, petugas, supervisor.
npm run test:e2e:uiMode interaktif Playwright, paling enak untuk menulis dan menelusuri test.
npm run test:e2e:headedBrowser terlihat, satu per satu.
npm run test:e2e:reportMembuka laporan HTML dari putaran terakhir.
npx playwright test -g "TC-KLH-011"Satu test case berdasarkan ID-nya.
npx playwright test e2e/ui/staff.spec.tsSatu berkas.

Kalau menyalakan stack sendiri agar putaran berulang lebih cepat, jalankan node e2e/support/start-stack.mjs di terminal lain, lalu E2E_REUSE=1 npx playwright test. Datanya menumpuk sampai stack dinyalakan ulang, dan kuota Kato Bot (20 pertanyaan per hari per alamat) bisa habis.

9. Menulis test baru

import { expect, test, unique } from '../fixtures';

test('TC-KLH-018 foto kotor ditolak', async ({ api, newStaff }) => {
  const { id } = await api.report({ description: unique('[vision:dirty] keluhan') });
  const res = await api.resolve(id, (await newStaff()).id);
  expect(res.status()).toBe(422);
});
  1. Impor dari e2e/fixtures.ts, bukan langsung dari @playwright/test.
  2. Mulai judul dengan ID test case, tambahkan @mobile kalau alurnya dipakai di HP, dan @smoke hanya untuk alur paling inti.
  3. Buat data sendiri dengan unique(). Test berjalan paralel pada satu database, dan teks yang sama di lokasi yang sama dianggap laporan kembar selama dua menit. Jangan menghitung baris global: test lain mungkin sedang menambah data.
  4. Pakai newStaff() agar nama petugas tidak bentrok, dan api.report() karena laporannya dibersihkan otomatis saat test selesai.
  5. Cari elemen seperti pengguna: getByRole, getByLabel, lalu teks. Jangan memakai kelas Tailwind. Antarmuka pengujian memakai bahasa Indonesia (locale: id-ID).
  6. Pakai helper yang ada: pick() untuk dropdown (Select.tsx bukan <select> biasa) dan takePhoto() untuk kamera.
  7. Jangan membiarkan data yang merusak tampilan di database bersama. Suntikkan lewat page.route() untuk halaman itu saja, seperti test TC-UIX-009.

Mencatat bug yang belum diperbaiki

Tulis test untuk perilaku yang benar, lalu panggil knownIssue() tepat sebelum assertion yang menunjukkan bug-nya. Kegagalan langkah persiapan di atasnya tetap terbaca sebagai kegagalan biasa.

const res = await request.patch(`/api/reports/${id}`, { data: { status: 'resolved', staff_id: second.id } });
knownIssue('T-05', 'penangan dan waktu selesai bisa ditimpa tanpa foto');
expect(res.status()).toBe(409);

Begitu bug diperbaiki, test ini lulus dan Playwright melaporkannya sebagai kegagalan. Itulah tanda untuk menghapus baris knownIssue, sehingga test berubah menjadi penjaga regresi.

10. Mengatasi masalah

GejalaPenyebab dan solusi
Executable doesn't existBrowser belum terpasang: npx playwright install chromium.
http://127.0.0.1:8788 is already usedStack dari putaran sebelumnya masih hidup. Cari dengan lsof -nP -iTCP:8788 -sTCP:LISTEN, lalu hentikan prosesnya. Atau pakai port lain: E2E_PORT=8790 E2E_MOCK_PORT=8800.
Stack gagal menyala atau timeoutJalankan node e2e/support/start-stack.mjs langsung untuk melihat keluarannya, biasanya migrasi atau seed yang gagal.
Semua test UI skippedProyek setup gagal, biasanya karena login admin. Kalau password di migrasi diganti (T-04), perbarui ADMIN di e2e/fixtures.ts.
Kamera tidak siap, tombol potret tetap nonaktifBendera kamera sintetis hanya ada di Chromium. Pastikan proyek yang dijalankan desktop atau mobile.
Kato Bot membalas 429Kuota harian habis, biasanya saat memakai E2E_REUSE=1. Nyalakan ulang stack agar databasenya bersih.
Test gagal setelah mengubah teks UITest membaca teks dari web/src/lib/i18n.tsx. Kalau perubahannya disengaja, sesuaikan test-nya.
Muncul peringatan API key #1 of 2 refusedNormal. Mock sengaja menolak kunci pertama untuk menguji pergantian kunci.
